# retype

## 第三方数据与组件署名

本发行包中的**词库数据**来自以下项目：

### jieba 词频表
- 项目: https://github.com/fxsjy/jieba (MIT)
- Rust 移植: https://github.com/messense/jieba-rs (MIT)
  - Copyright (c) 2018 - 2019 messense
  - Copyright (c) 2019 Paul Meng
- 用途: `retype-dict.tsv` 的词条目与词频来自 jieba 的 `dict.txt`
  （349,045 行原始数据；构建时会过滤不适用的词条并展开多音字）
- 完整许可证文本见本目录 `LICENSE-jieba`

### pinyin 字音数据
- 项目: https://github.com/mozillazg/rust-pinyin (MIT)
- 数据源: https://github.com/mozillazg/pinyin-data (MIT)
- 用途: 构建期为汉字注音（含多音字），以及运行时的单字降级模式

### Unicode Unihan 读音频率数据
- 项目: https://www.unicode.org/reports/tr38/
- 数据: Unicode 15.1.0 `kHanyuPinlu`，源自《现代汉语频率词典》
- 用途: 按实际读音频率分配单字词频，避免“无 mó”等特定场景读音占据常用候选首位
- 许可: Unicode License V3；完整文本见本目录 `LICENSE-Unicode.txt`

## 数据隐私

- 用户词库、纠错记录、输入历史**全部保存在本机**
  （`%LOCALAPPDATA%\retype\`），默认不上传。
- 上下文（光标前后文本）带有隐私等级标记。密码框与密码管理器进程一律
  **不采集**；未显式允许的应用，上下文只在本地参与排序，不出网。
- 详见 `docs/auto-update.md` 与 `ARCHITECTURE.md` 第 4 节。
