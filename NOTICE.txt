# retype

## 第三方数据与组件署名

本发行包中的**词库数据**来自以下项目：

### 万象拼音 Base 词库
- 项目: https://github.com/amzxyz/rime-wanxiang
- 上游版本: v18.0.14，发布包 `rime-wanxiang-base.zip`
- 来源文件: `zi.dict.yaml`、`jichu.dict.yaml`、
  `lianxiang.dict.yaml`、`duoyin.dict.yaml`
- 用途: `retype-dict.tsv` / `retype-dict.bin` 的词条、逐词读音与权重。
  构建时去掉声调，保留拼音与权重，并过滤当前解码器
  尚不能使用的九字以上词条及非汉字词条。
- 许可: Creative Commons Attribution 4.0 International (CC BY 4.0)。
  上游词库及本项目的转换产物均保留该数据许可；完整文本见
  `LICENSE-wanxiang`（源码中为 `data/dict/raw/wanxiang-base/LICENSE`）。
  retype 与上游项目无关联，上游作者未为本项目背书。

### 万象拼音可选分类词库
- 项目: https://github.com/amzxyz/rime-wanxiang
- 上游版本: v18.0.14
- 可选文件: `dicts/mingren.dict.yaml`、`renming.dict.yaml`、
  `yiren.dict.yaml`、`diming.dict.yaml`、`yixue.dict.yaml`、
  `yaopin.dict.yaml`、`huaxue.dict.yaml`
- 用途: 用户在设置中选择后下载、校验并本机转换；这些数据不包含在安装包内。
- 许可: Creative Commons Attribution 4.0 International (CC BY 4.0)，
  完整文本见 `LICENSE-wanxiang`。

### pinyin 字音数据
- 项目: https://github.com/mozillazg/rust-pinyin (MIT)
- 数据源: https://github.com/mozillazg/pinyin-data (MIT)
- 用途: 词库缺失时的单字降级模式，以及开发辅助工具；默认词库使用万象逐词注音

### Unicode Unihan 读音频率数据
- 项目: https://www.unicode.org/reports/tr38/
- 数据: Unicode 15.1.0 `kHanyuPinlu`，源自《现代汉语频率词典》
- 用途: 单字降级与开发辅助工具中的多音字权重；不参与默认万象词库的构建
- 许可: Unicode License V3；完整文本见本目录 `LICENSE-Unicode.txt`

### English word frequencies
- Source: https://github.com/wolfgarbe/SymSpell, commit c239062ae02961df18ab7da1671d01b4388204e0
- File: SymSpell/frequency_dictionary_en_82_765.txt, by Wolf Garbe.
- Upstream combines SCOWL word lists (Kevin Atkinson and contributing word-list authors)
  with Google Books Ngram frequencies (https://books.google.com/ngrams/).
- Google Ngram data is licensed under CC BY 3.0; SCOWL carries its own word-list
  notices and permissions. See LICENSE-Google-Ngram, LICENSE-SCOWL and LICENSE-SymSpell.
- retype filters unsupported non-ASCII entries and precompiles prefix indexes;
  spelling suggestions use an independently implemented bounded one-edit search.
- The compiled English data retains its upstream notices and applicable data licenses;
  those licenses are separate from retype's MIT code license.

## 数据隐私

- 用户词库、纠错记录、输入历史**全部保存在本机**
  （`%LOCALAPPDATA%\retype\`），默认不上传。
- 上下文（光标前后文本）带有隐私等级标记。密码框与密码管理器进程一律
  **不采集**；未显式允许的应用，上下文只在本地参与排序，不出网。
- 详见 `docs/auto-update.md` 与 `ARCHITECTURE.md` 第 4 节。
