# retype 0.1.4 — 修复输入法名称乱码和无法切换

本版修复 0.1.3 安装后的两个问题：设置中的名称出现乱码，以及设置中已添加 retype、但 Win+Space 列表中仍不出现。

## 修复内容

- 注册输入法时为名称与图标路径补齐 UTF-16 结束符，避免系统将字符串后面的内存内容写入名称。
- 安装时除了添加当前用户的键盘列表，还显式启用 TSF 语言配置并读取验证，修复“已添加但未启用”的状态。保留其他键盘与默认输入法设置。
- 增强安装验收：检查注册名称完全匹配、语言配置已启用，以及已安装 DLL 可以加载并激活。

## 升级

下载 `retype-0.1.4-windows-x64-setup.exe` 覆盖安装，无需先卸载。安装器会重新注册名称并修复当前用户的启用状态。

完成后重新打开使用输入法的应用，再用 Win+Space 选择 retype；若安装器要求重启，请按提示操作。系统设置仍显示旧名称时，关闭并重新打开设置；如果会话仍保留旧状态，可保存工作后注销并重新登录。

安装包面向 x64 Windows，包含 x64 和 x86 输入组件。小鹤双拼、全拼和横排候选窗保持可用。仍为桌面预览版；Ctrl+Space 中英文切换尚未完成实际兼容性验证，请优先点击语言栏「中 / A」。

安装包尚未代码签名，下载旁附 SHA256 校验文件。
