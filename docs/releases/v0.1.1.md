# retype 0.1.1 —— 安装包取代 zip

**这是一个发布方式修正版本，功能与 0.1.0 相同。**

0.1.0 发的是 zip，用户得手动解压、再 `ExecutionPolicy Bypass` 跑脚本注册 ——
对输入法这种要写 HKLM 注册表键、要把 8.9MB 词库放进 Program Files、
还要处理「TIP DLL 正被所有宿主进程占用」的东西来说，这是不负责任的发布方式。
0.1.1 起发 **Inno Setup 安装包**。

## 安装

下载 `retype-0.1.1-windows-x64-setup.exe`，双击运行（需要管理员权限，因为要写 HKLM）。

装完**必须注销并重新登录** —— TSF 的语言配置档被登录会话缓存，
不注销的话输入法不会出现在 Win+Space 的列表里。结束页会明确提示这一点。

### 从 0.1.0（zip）升级

0.1.0 不是用安装器装的，系统里没有它的卸载条目，所以直接运行 0.1.1 的安装包即可，
会装成一份全新的。如果你当时用 `register.ps1` 注册过，先跑一次
`register.ps1 -Unregister` 清掉 HKCU 里的旧键，避免两套注册互相干扰。

## 安装器做了什么

| 事项 | 做法 |
|---|---|
| TSF 注册 | 写 HKLM 的 `InprocServer32`（`ThreadingModel=Apartment`）+ `LanguageProfile`，卸载时反向清理 |
| 词库落位 | 装到 `{app}\retype-dict.tsv`（DLL 同目录） |
| DLL 被占用 | `CloseApplications=yes` 走 Restart Manager：列出占用进程让你选择关闭；关不掉的自动登记为「重启后替换」 |
| 不擅自重启你的应用 | `RestartApplications=no` |
| 跨版本升级 | `AppId` 固定不变，Inno 据此识别为同一产品并原地升级 |
| 卸载 | 询问是否删除个人词库（默认否 —— 你积累的选词习惯比一次干净卸载更值钱） |
| 开始菜单 | 「retype 调试台」（终端里体验完整输入链路，不需要注销）、「检查更新」 |

## 本版本顺带修的两个 bug

1. **TIP 找不到词库**。TIP 的工作目录是宿主进程的（notepad、chrome……），
   而安装器把词库放在 Program Files。0.1.0 的 `default_dict_path()` 只找
   `%LOCALAPPDATA%`，装完会退化成「原样字母」模式。
   现在用 `GetModuleHandleExW(FROM_ADDRESS)` 定位 **DLL 自己所在的目录**，
   查找顺序改为：环境变量 → DLL 同目录 → `%LOCALAPPDATA%`。
2. **sha256 解析器不接受带 BOM 的文件**。PowerShell 的
   `Set-Content -Encoding UTF8` 默认写 BOM，而 U+FEFF 在 Rust 里不算空白字符，
   `trim()` 去不掉，导致「校验文件里没有对应条目」这种误导性报错。现在容忍 BOM 和 CRLF。

## 自动更新

`retype-updater.exe`（装在 `{app}\` 下）：

```powershell
& "C:\Program Files\retype\retype-updater.exe" check      # 0=已最新 10=有更新
& "C:\Program Files\retype\retype-updater.exe" download --out "$env:TEMP\retype-update"
```

校验通过后静默升级：

```powershell
& "$env:TEMP\retype-update\retype-0.1.1-windows-x64-setup.exe" /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```

`/NORESTART` 是刻意的：由调用方决定何时提示重启，而不是让安装器在你打字打到一半时重启机器。

## 已知问题（与 0.1.0 相同）

- **还不能在系统里打中文**：组字串读写（TSF 的 `ITfEditSession`）是 M1 的工作。
  注册后不会吞掉你的按键（TIP 一律返回「不吃这个键」），但也打不出中文。
  想体验完整输入链路，用开始菜单里的「retype 调试台」。
- **未代码签名**：setup.exe 会触发 SmartScreen 警告（「Windows 已保护你的电脑」）。
  发布给真实用户之前必须解决，见 roadmap M5。
- 只有 x64 安装包。32 位应用需要 x86 TIP，M1 补齐。
- TIP DLL 1,082 KB 偏大（大头是 `pinyin` crate 内嵌的全量字音数据），M1 压到 ~300KB。

## 校验

```powershell
certutil -hashfile retype-0.1.1-windows-x64-setup.exe SHA256
# 与 retype-0.1.1-windows-x64-setup.exe.sha256 里的值比对
```
