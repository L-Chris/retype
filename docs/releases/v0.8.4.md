## Feature

- Connect clipboard sync over Tailscale or a specified device address on Windows, macOS, and Android, while keeping existing device links when networks change.

## Improvement

- Use a centered monochrome menu bar icon on macOS that adapts to light and dark appearances.

## Fix

- Restore opening settings from the macOS input menu, including hidden and minimized windows.
- Refresh the macOS input menu after installation and updates so the new icon takes effect.

## Feature

- Windows、macOS 和 Android 支持通过 Tailscale 或指定设备地址同步剪贴板，切换网络后保留原有设备关联。

## Improvement

- macOS 菜单栏改用居中的单色图标，自动适配浅色和深色外观。

## Fix

- 修复从 macOS 输入法菜单打开设置的问题，并恢复隐藏或最小化的设置窗口。
- 安装和更新后刷新 macOS 输入法菜单，让新图标及时生效。
