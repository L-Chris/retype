## Feature

- Select retype in Windows search and other modern Windows text fields.

## Improvement

- Xiaohe Shuangpin now offers candidates for incomplete three-key input without appending unmatched letters to them.
- The smaller candidate window shows up to eight choices per page, with `-` and `=` for paging.
- Wanxiang Base expands phrase coverage and preserves each word's pronunciation for more accurate candidates.
