## Improvements & Fixes

- Redesign the Settings UI across macOS, Windows, and Android with a cleaner card layout, compact vector icon buttons, and a streamlined 3-card Cross-Device clipboard sync view.
- Fix sidebar scrollbar overlap and navigation icon shifting on macOS and Windows.
- Fix vertical text centering and active field character clipping in macOS settings inputs.
- Consolidate macOS Keychain credentials into a single vault item to avoid repeated Keychain authorization prompts across app updates.
- Fix macOS Cloud Sync connection tests failing with `invalid type: integer '1', expected a boolean` after toggling sync switches.

## 优化与修复

- 重构 macOS、Windows 与 Android 端设置界面：统一卡片布局、精简提示文案、替换为直观的矢量图标按钮，并将「跨设备」剪贴板同步重构为清晰的卡片式结构。
- 修复 macOS 与 Windows 设置侧边栏激活背景与滚动条重叠、激活时导航图标位置抖动的问题。
- 修复 macOS 设置输入框文字未垂直居中及激活输入时字符顶部被截断的问题。
- 优化 macOS 钥匙串凭据存储（合并为单一保险库条目并支持本地签名身份检测），避免更新版本后重复弹出钥匙串授权提示。
- 修复 macOS 云同步切换开关后点击测试报 `invalid type: integer '1', expected a boolean` 以及修改用户名后密码未按最新账号保存的问题。
