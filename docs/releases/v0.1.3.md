# retype 0.1.3 — M1 桌面输入预览

本版接通 Windows 桌面应用中的中文组字和候选上屏，加入语言栏状态图标、小鹤双拼和紧凑横排候选窗。

## 安装与使用

下载 `retype-0.1.3-windows-x64-setup.exe`，可覆盖升级，无需先卸载。安装包面向 x64 Windows，同时包含用于 64 位和 32 位桌面应用的 TIP DLL。

安装后重新打开使用输入法的应用；若安装器要求重启，请按提示操作。通过 Win+Space 选择 retype。安装器会为当前用户添加输入法，也提供开始菜单中的用户配置入口。

- 点击语言栏「中 / A」切换中英文，右键菜单选择全拼或小鹤双拼；方案会保存。
- 全拼输入 `nihao`，小鹤输入 `nihc`，空格选择「你好」。
- 数字 1–5 或鼠标选择当前页候选，左右键移动选择，PgUp/PgDn 翻页。
- Backspace 删除拼音，Esc 取消组字，Enter 提交原始拼音。

## 更新

- 修复 TSF 注册和当前用户输入法配置，安装时同时注册 x64、x86 DLL，并传递注册失败信息。
- 实现 TSF 编辑会话、组字下划线、候选上屏及焦点和文档生命周期处理。
- 新增「中 / A」语言栏图标和输入方案菜单，同步系统中英文开关。
- 保留全拼，新增小鹤双拼，按原始按键位置处理分词、部分选词和退格。
- 候选窗改为原生紧凑横排，使用圆角、浅蓝选中态和每页五项候选；支持鼠标选词、屏幕边界避让和 DPI 缩放。
- 新增预解析二进制词库和异步加载，减少运行时解析开销；保留 TSV 调试词库。
- 发布流程增加 x86 构建与测试，以及临时注册后的安装验收检查。

## 验证与限制

本地工作区发布模式测试 216 项通过，x86 TSF 测试 28 项通过，格式和 Clippy 检查通过。独立 RichEdit 宿主已验证真实按键组字、空格上屏、小鹤输入和鼠标选词。

这是桌面预览版，尚未完成所有主流应用、Windows 任务栏样式、高 DPI、深色和高对比度环境的兼容性验收。AppContainer 支持尚未启用。

- Ctrl+Space 已接入，但本机实际触发尚未验证成功；目前请点击语言栏图标切换中英文。
- 词库刚加载时可能短暂显示原始字母候选。
- 安装包尚未代码签名。

下载旁附 SHA256 校验文件。更多验证记录见仓库中的 `docs/m1-validation.md`。
