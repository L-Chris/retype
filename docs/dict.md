# 词库数据管线

## 默认数据

retype 的默认词库来自[万象拼音 Base v18.0.14](https://github.com/amzxyz/rime-wanxiang/releases/tag/v18.0.14)。
仓库保存了上游的单字、基础词、联想词和多音词四份原始 Rime 词典；
来源、校验和及许可见 [SOURCE.md](../data/dict/raw/wanxiang-base/SOURCE.md)。
构建器直接使用上游逐词注音与权重，不再由单字读音推测整个词的发音。
因此「奇数」保留 `jī shù`，小鹤双拼输入 `jiuu` 能找到它。

Base 词典按词保存带调拼音，例如 `jī shù`；构建时只去掉声调。
当前 retype 不支持万象 Pro 的辅码筛选、Lua 功能或语法模型。
全拼和小鹤双拼共用同一份去声调词库。

构建器只纳入汉字词和最多八字的词条，与解码器当前的
`max_word_syllables = 8` 一致。专业分类词库不放入默认安装包，
可在设置的「词库」页按需下载并开启。

## 可选分类词库

设置页提供万象拼音 v18.0.14 的名人、常用人名、艺人、地名、医学、
药品、化学七类词库。首次开启时从固定版本的上游地址下载原始词典，
用内置 SHA-256 和大小校验，再由安装包附带的构建器在本机转换为二进制
词库。未选择的词库不会下载；关闭后保留文件，用户可单独删除。
下载产物保存在 `%LOCALAPPDATA%\retype\dict-packs`，不随程序升级删除。

启用状态记录在当前用户设置中。输入法在下一次获得焦点时，后台加载
启用的词库并替换内存快照；输入线程不进行下载或磁盘读取。Windows
搜索等 AppContainer 宿主对该目录仅有读取权限。分类词库保留上游逐词
读音和权重，加载时将其概率换算到基础词库的权重总量，以免小词库
因为单独归一化而占据候选首位。

## 构建与检查

仓库中的原始词典可离线构建；产物位于 `data/dict/`，不提交 Git：

```powershell
cargo run -p retype-dict-build --release -- --out data/dict/retype-dict.tsv
cargo run -p retype-diag --release -- --dict data/dict/retype-dict.bin --scheme flypy --explain jiuu
cargo run -p retype-diag --release -- --dict data/dict/retype-dict.bin --scheme flypy --bench
```

构建器读取 `词<TAB>带调拼音<TAB>权重`，产出
`词<TAB>无声调拼音<TAB>权重` TSV，再编译成 `RTDICT02` 二进制词库。
无效音节、非汉字词条、超过八字的词条会跳过；构建结束后回读二进制，
核查「奇数」「快捷键」「没收」「南无」等词的读音。
`--in` 可重复指定其他 Rime 词典；`--min-weight` 和
`--max-word-len` 可调整过滤阈值。

原有五字上限产出约 155 万条有效词条；八字上限的具体大小以本次构建产物为准。
词库在后台线程加载，不阻塞 TSF 激活线程。词库大小高于旧版
Jieba 词库，后续若要压缩，应优化二进制编码或有依据地裁剪词条，
避免直接降低常用词覆盖率。

`RTDICT02` 在构建时完成排序、去重和词频归一化，保存连续的节点、边、
词条编号和文本区域。运行时验证边界、索引、音节和 UTF-8 后直接查询，
不再重建前缀树；只有命中的候选才创建字符串。
Windows 使用只读文件映射，并保留禁止写入共享的文件句柄，避免映射期间
文件被原地修改或截断。同一进程通过文件身份和弱引用复用词库；
原子替换后可加载新文件，已有会话继续安全使用旧文件。
缓存键直接使用已打开文件的身份，不再要求查询规范路径；Windows 搜索等
AppContainer 宿主可能允许读取、映射文件，却拒绝规范路径查询。
基础词库加载失败后暂用单字兜底，下次获得焦点时可后台重试，间隔至少五秒；
可选词库等待基础词库成功加载，再使用其词频总量。Windows 启动日志中的
`dictionary_load` 记录路径、成功状态、词条数、耗时和错误，不记录输入内容。
扩展词库采用相同格式和加载路径；旧 `RTDICT01` 仍可读取，但使用旧内存表示。
词库数据的映射页仍占用物理内存，由系统在进程间共享，并不是没有内存开销。

## 候选排序

词典权重由上游维护，**不是与旧版 Jieba 频次可直接相加的语料计数**。
加载器按 `logp(w) = ln(weight_w / Σweight)` 归一化。
解码器先查询覆盖全部输入的完整词条，系统词库、可选词库和用户词库
采用同一规则；命中后按词条概率和个人学习排序，并保留低频同音词供翻页。
只有没有完整词条时才启用自动组词，避免高频单字拼接抢占整词候选。
自动组词路径的得分仍为 `Σ(logp(w_i) + word_bonus)`，
`word_bonus` 默认 3.5，最多保留 24 条路径；这部分尚未接入搭配语言模型。
小鹤双拼完整编码的整词先于末音节补全；没有完整整词时保留补全预览，
延续按音节平均分比较补全与前缀的顺序，较短的前缀仍可选择。
显式音节分隔符限制切分边界，不阻止整词跨音节匹配。
因此仅更换词库不能保证所有候选顺序正确，仍需针对真实输入验收排序。
