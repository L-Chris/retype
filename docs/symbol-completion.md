# 符号自动补全

桌面和 Android 的「设置 → 输入」均提供开关，默认开启，并随输入设置进行云同步。

直接键入左符号时，retype 补入右符号，将光标留在两者之间。

- 中文：`（）`、`【】`、`《》`、`“”`、`‘’`。
- 英文：`()`, `[]`, `{}`, `""`, `''`。
- 直接输入的中文符号也支持补全，包括 `「」`、`『』`。

光标紧邻 retype 本次输入补出的右符号时，再键入对应右符号会跳过它；空符号对内退格会删除整对。拼音正在组字时，退格仍优先删除拼音。嵌套符号对也适用。

英文单词中的撇号和拼音分隔符保留原用途。英文 `<`、`>` 不补全。粘贴、翻译和语音结果不会触发补全。选中文字后输入符号保持普通替换行为。

不会将应用内已有的右符号当作 retype 生成的符号；遇到已有同类右符号，不再补入第二个。切换输入框或输入法后，放弃自动补出的符号的归属。应用不支持读取附近字符或定位光标时，退回普通单符号输入。

两端共用 Rust 符号映射。Windows 在 TSF 写锁内使用原生文本范围与选择区，Android 使用 InputConnection 批量编辑及选择区回调；不模拟方向键、不扫描整个输入框。每个输入会话最多跟踪 32 个右符号。
